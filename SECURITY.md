# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of WallCut.

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| Older releases | No guarantee |

## Reporting a Vulnerability

If you discover a potential security vulnerability in WallCut, please report it responsibly.

**Email:** wallcut@proton.me

Please include the following information in your report, if possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs, screenshots, or proof-of-concept code.
- Any suggested mitigation, if known.

Please do not publicly disclose the vulnerability in a GitHub issue, pull request, or discussion until it has been reviewed and the maintainers have had a reasonable opportunity to address it.

## Response Process

After receiving a report, the project maintainers will aim to:

1. Acknowledge receipt of the report.
2. Assess the reported vulnerability and its potential impact.
3. Investigate and work on a fix where appropriate.
4. Coordinate disclosure with the reporter when possible.

Response times may vary depending on the severity and complexity of the issue and the maintainers' availability.

## Scope

This policy covers security vulnerabilities in the WallCut project and its officially maintained components.

Reports about unrelated third-party software should be submitted to the respective project's maintainers.

## Responsible Disclosure

We appreciate the work of security researchers and community members who help improve WallCut's security. We ask that you make a good-faith effort to avoid privacy violations, data destruction, service disruption, and other harm while investigating potential vulnerabilities.
